# Nexport Dynamics Limited — 3D Website

This ZIP is the 3D version of the Nexport Dynamics website using the supplied Nexport logo.

Features:
- Transparent-background Nexport logo
- Brand colors: navy, royal blue, sky blue and orange
- Three.js 3D animated globe, orbital trade routes and cargo containers
- 3D service cards with hover depth
- 3D minerals presentation
- Source → Warehouse → Port → World logistics flow
- Cargo tracking UI
- Quote request form
- Responsive mobile/desktop layout

IMPORTANT:
This version is fully self-contained and does NOT require Three.js, npm, a web server, or an internet connection for the 3D hero animation.

How to open:
1. Extract the ZIP.
2. Open index.html directly in Chrome, Safari, Edge, or Firefox.
3. The 3D-style globe and animations should display immediately.

If opening from iPhone Files, extract the ZIP first and open index.html in a browser.
